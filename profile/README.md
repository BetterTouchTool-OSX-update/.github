## Quick Troubleshooting

| Issue | Fix |
|---|---|
| Gestures or shortcuts do nothing | Confirm Accessibility and Input Monitoring are granted in System Settings › Privacy & Security |
| A gesture triggers by accident | Choose a more distinct trigger, or scope it to a single app instead of global |
| Window snapping doesn't resize | Enable the window-snapping actions and re-grant Accessibility if you just updated macOS |
| Settings vanished after reinstall | Import the configuration you exported, or set up a regular export as backup |
